## 🚀 Getting Started

### Prerequisites
* **Java SDK (JDK) 17 or later** is recommended to compile and run modern features (lambdas, records, collections).
* Any text editor or IDE: **VS Code** (with Extension Pack for Java), **IntelliJ IDEA**, or **Eclipse**.

### Running Java Files
You can clone this repository locally and run the programs via standard terminal compile commands:

```bash
# Clone the codebase
git clone https://github.com/garvit-mishra-beep/JAVA.git
cd JAVA

# Compile a specific file (e.g. PrefixSum in Arrays folder)
javac Arrays/PrefixSum.java

# Execute the compiled class file
java -cp Arrays PrefixSum
javac FileName.java
java FileName
```

### Running LeetCode Solutions
**Example:**
```bash
# Compile the target solution class
javac leetcode/TwoSum_LC1.java

# Run it
java -cp leetcode TwoSum_LC1
javac BubbleSort.java
java BubbleSort
```
