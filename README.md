*   [CollegePortal.java](OOP/Encapsulation/CollegePortal.java): Student/Faculty encap record registry.
*   [OOPBasicsDemo.java](OOP/Encapsulation/OOPBasicsDemo.java): Driver demonstrating basic class instance initialization.

#### 📂 Inheritance
*   [AnimalInheritance.java](OOP/Inheritance/AnimalInheritance.java): Single and hierarchical inheritance demo.
*   [PrinterInheritance.java](OOP/Inheritance/PrinterInheritance.java): Printing formats override across printer classes.
*   [VehicleInheritance.java](OOP/Inheritance/VehicleInheritance.java): Multilevel inheritance demonstration using Vehicle -> Car -> ElectricCar.

#### 📂 Polymorphism
*   [ShapePolymorphism.java](OOP/Polymorphism/ShapePolymorphism.java): Method overriding and polymorphism using area/perimeter of 2D shapes.

```bash

# Navigate to the project folder
cd JAVA

# Compile any Java file (e.g. from the Sorting folder)

# Run the compiled program
java Sorting.BubbleSort
```
