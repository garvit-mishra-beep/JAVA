## 🚀 Getting Started

### Prerequisites
- **Java 17+** (or Java 8+ for basic programs)
- Any IDE: **IntelliJ IDEA**, **Eclipse**, or **VS Code** with the Java Extension Pack

### Run Any Program

```bash
# Clone the repository
git clone https://github.com/garvit-mishra-beep/JAVA.git
cd JAVA

# Compile a file
javac Arrays/PrefixSum.java

# Run it
java -cp Arrays PrefixSum
```

### Run a LeetCode Solution

```bash
javac leetcode/TwoSum_LC1.java
java -cp leetcode TwoSum_LC1
```
